# docs/

Additive and shared. Everyone's agent reads all of it; the rule for writing keeps it conflict-free:

- **Add new files freely.** Never edit a file someone else wrote.
- `docs/lanes/<lane>/` is that lane's own space: `CONTRACT.md` (what the lane exposes/consumes), `SEEDED.md` (what sample data is preloaded, and any stub still standing), notes.
- `docs/BRIEF.md` (the hackathon brief) and `docs/DEMO.md` (the 90-second script, cut list) belong to the lead lane. To change them: `scripts/hack request <lead-lane> "..."`.
- `docs/agents/` is how the skills are configured for this repo.
